# General Information

Catch the Trash is a game about collecting ocean rubbish while avoiding marine life (fish). I created it to explore how game mechanics and visual effects can communicate the consequences of littering on marine life.

# Technologies Used

- Microsoft MakeCode Arcade
- Python

# Features

- Move a net around the screen using the directional controls
- Collect rubbish to increase the score
- See a confetti effect when rubbish is collected
- If the net catches a fish, it changes to a dead-fish image and the game ends

# Setup and Usage

No separate Python installation is required. Open the Catch The Trash project link (https://arcade.makecode.com/S21445-57824-53184-89747) in a browser to run the game.

Use the directional controls to move the net, collect rubbish, and avoid the fish.

Once the game is over, select 'A' to restart.
